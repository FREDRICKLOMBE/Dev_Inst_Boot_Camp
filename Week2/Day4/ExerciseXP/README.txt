Exercises XP - Python File I/O and JSON

Both exercises from the assignment page are included. The Python files follow
DailyChallenge_Circle.py's style: star-marked headings, short function docstrings,
plain explanatory comments, section labels and a main guard.

Files
Exercise1_RandomSentence.py - Read words and generate a random sentence.
Exercise2_WorkingWithJSON.py - Print the salary, add a birth date and save JSON.
words.txt - Original assignment word list (44,185 words).
employee.json - Actual output generated by running Exercise 2.
Sample_Output.txt - Actual example runs, including invalid input cases.

Run from the folder containing these files:
py -E Exercise1_RandomSentence.py
py -E Exercise2_WorkingWithJSON.py

The -E option ignores Python environment variables. It was needed on this
computer because PYTHONHOME points to a different Python installation.
No extra packages are required. Keep words.txt beside Exercise1_RandomSentence.py.
Exercise 2 writes employee.json beside its script, replacing that file on reruns.

Exercise 1
Enter an integer from 2 to 20 inclusive. The program prints that many random
words in lowercase. Words may repeat, and the result need not be grammatical.
Invalid input prints an error and ends the program. Sample sentences vary on
each run because the program uses random.choice().

Exercise 2
json.loads() turns the supplied JSON string into a dictionary. The salary is
7000. The birth_date key belongs directly inside the employee dictionary.
1998-04-15 is an example birthday, not a known fact about Emma. json.dump()
saves the entire modified dictionary with four-space indentation.
The starter code's missing closing triple quotes have been corrected.

Verified
All sentence lengths from 2 through 20, lowercase output, word-list membership,
invalid input, empty and missing word files, and the complete saved JSON.
